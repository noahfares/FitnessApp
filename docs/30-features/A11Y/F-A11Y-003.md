# F-A11Y-003 — Contrast and colour independence

Status: done | Priority: P1 | Phase: 6
Reads: 24-DESIGN-SYSTEM#accessibility-baseline

## Spec

4.5:1 for text and 3:1 for interactive boundaries, in both schemes. No
information conveyed by colour alone — set types carry letters, chart series
carry shapes, PRs carry an icon.

## Implementation

Three of the four requirements predate this feature, which is why it is small:

- **Set types carry letters** — `SetLabel.badge` (`D`, `F`, `A`, `B`) since
  `F-LOG-005`.
- **PRs carry an icon** — `PrBadge`, since `F-LOG-013`.
- **Chart series carry shapes** — the secondary series is a line-less scatter
  and the regression overlay is dashed (`TrendChart`), so neither depends on
  colour to be told apart.
- **Plate colours** were the one real colour-only encoding left. They follow
  the IPF convention, which is defined in colour by definition, so the same
  information is now spoken instead of removed.

Contrast was already pinned for `AppColors`' semantic roles; this feature adds
the `ColorScheme`'s own text pairs at 4.5:1 and `outline` against `surface` at
3:1, in both schemes, so a future seed change cannot quietly fail the criterion.
