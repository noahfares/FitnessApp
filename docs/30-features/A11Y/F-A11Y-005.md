# F-A11Y-005 — Reduce motion

Status: done | Priority: P2 | Phase: 6
Reads: 24-DESIGN-SYSTEM#accessibility-baseline

Honour the system reduce-motion setting: no chart animations, no PR celebration
animation, instant transitions.

## Status note

Batch 6.1 covered the chart and PR-badge animations. `ReducedMotionPageTransitionsBuilder`
(`lib/core/theme/app_theme.dart`) closes the remaining "instant transitions"
clause: it wraps every platform's default `PageTransitionsBuilder` in
`AppTheme`'s `pageTransitionsTheme` and returns the incoming child untouched
— no fade, no slide, no scale — whenever `MediaQuery.of(context).disableAnimations`
is true, delegating to the normal platform transition otherwise.
