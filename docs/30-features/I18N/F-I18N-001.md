# F-I18N-001 — String externalisation

Status: done | Priority: P1 | Phase: 6
Reads: 22-UNITS, 24-DESIGN-SYSTEM

## Spec

All user-facing strings in ARB files from the start, even while English-only.
Retrofitting extraction across a finished app is miserable and never quite
complete; doing it continuously costs almost nothing.

## Implementation

- `flutter_localizations` + `gen-l10n`, configured in `l10n.yaml`, generating
  into `lib/l10n/` and **committed** — the same rule the Drift `*.g.dart` files
  follow, so IDEs and CI need no codegen step before the app compiles.
- `context.l10n` (`lib/core/l10n/l10n.dart`) rather than
  `AppLocalizations.of(context)`: the long form is what makes externalisation
  feel expensive at the call site, and a rule that feels expensive gets skipped
  for "just this one string".
- ~600 keys, prefixed by feature area. Plurals are ICU messages, not Dart
  ternaries — `count == 1 ? 'set' : 'sets'` is an English rule, and it was in
  the code a dozen times.
- **Enum display names moved into the ARB.** `exercise_labels.dart` and friends
  became `String label(AppLocalizations l10n)`, which is exactly what that
  file's own doc comment anticipated ("these become the localisation surface in
  `F-I18N-001`"). `RestAlertStyle`'s label moved out of `lib/domain/` entirely,
  since the domain layer imports nothing from Flutter; the behaviour getters
  stayed, because those are rules rather than text.
- Text-composing functions (`progressionRationaleText`, `weeklyInsightText`,
  chart summaries) take an `AppLocalizations` parameter instead of reading a
  context, which keeps them unit-testable — `test/support/l10n.dart` is the one
  line those tests need.
- A localised default cannot be a `const` parameter value, so shared components
  (`ErrorView`, `ConfirmSheet`, `PrBadge`) take nullable labels and resolve the
  fallback where a context exists.
- `tools/check-strings.sh` runs in CI. Having paid the retrofit cost once, this
  is what stops it accruing again: a literal that reaches a screen fails the
  build the day it is written. Its own docstring records what is deliberately
  out of scope — SQL, `toString()`, the domain layer's proper nouns, and the
  data layer, which has no context and returns outcomes for the UI to word.

Still English-only, by design: the point was never a second language today, it
was that adding one is a new `.arb` file rather than a sweep through fifty
screens.
